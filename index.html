  • Suporta geração de roteiro de vídeo multilíngue

  • Suporta música de fundo aleatória ou personalizada com volume ajustável
  • Suporta seus próprios ativos locais e filmagens HD gratuitas de Pexels, Pixabay e Coverr
  • Suporta provedores de modelos líderes incluindo Kimi / Moonshot AI, OpenAI, Google Gemini, DeepSeek, Alibaba Cloud Qwen, Microsoft Azure OpenAI, ByteDance VolcEngine Ark, xAI Grok, MiniMax e Xiaomi MiMo, além de gateways unificados, agregadores e runtimes locais como Cloudflare AI Gateway, Alibaba ModelScope, AIHubMix, AIML API, EvoLink, Ollama, OneAPI, LiteLLM, Groq e Pollinations AI
  • Suporta publicação multiplataforma com um clique no TikTok, Instagram e YouTube Shorts após a geração do vídeo

Requisitos do Sistema 📦

  • Plataformas recomendadas: Windows 10+, macOS 11+ ou uma distribuição Linux mainstream
  • A implantação local requer Python 3.11 ou posterior; Python 3.11 é recomendado
  • Uma GPU não é necessária, mas é recomendada se você quiser transcrição local mais rápida, processamento de vídeo mais rápido ou geração em lote mais suave
Item Mínimo Recomendado Ótimo
CPU 4 núcleos 6 a 8 núcleos 8+ núcleos
RAM 4 GB 8 GB 16+ GB
GPU Não necessária 4+ GB VRAM 8+ GB VRAM
  • Se você depende principalmente de LLMs na nuvem, TTS na nuvem e fontes de material online, CPU e RAM importam mais do que GPU
  • Se você usa faster-whisper, geração em lote ou processamento local mais pesado, uma GPU melhorará o throughput de forma notável

Instalação e Implantação 📥

Pré-requisitos

  • A implantação local requer Python 3.11 ou posterior
  • No Windows, evite caminhos de projeto contendo caracteres não-ASCII, caracteres especiais ou espaços

① Clonar o Projeto

git clone https://github.com/harry0703/MoneyPrinterTurbo.git

② Configurar o Projeto (Opcional)

No primeiro lançamento, o projeto cria config.toml a partir de config.example.toml. Você pode configurar o provedor de LLM, fonte de filmagens e chaves de API relacionadas diretamente nas configurações básicas da WebUI.

Implantação com Docker 🐳

① Iniciar o Contêiner Docker

Se você ainda não instalou o Docker, instale-o primeiro em https://www.docker.com/products/docker-desktop/

Se estiver usando um sistema Windows, consulte a documentação da Microsoft:

  1. https://learn.microsoft.com/pt-br/windows/wsl/install
  2. https://learn.microsoft.com/pt-br/windows/wsl/tutorials/wsl-containers
cd MoneyPrinterTurbo
docker compose -f docker-compose.release.yml up
O padrão recomendado é docker-compose.release.yml, que puxa a imagem pré-construída do GitHub Container Registry: ghcr.io/harry0703/moneyprinterturbo:latest.
Se você precisar construir a imagem localmente, ainda pode executar docker compose up.
Antes do primeiro início, copie config.example.toml para config.toml para que possa ser montado nos contêineres.

Implantação Manual 📦

① Criar um Ambiente Virtual Python

Use o uv para gerenciar o ambiente Python e as dependências. O projeto suporta Python 3.11 ou posterior; o exemplo abaixo usa Python 3.11.

git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
uv python install 3.11
uv sync --frozen

Se você ainda não estiver usando uv, ainda pode usar venv + pip.

python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

Notas:
• pyproject.toml agora é o manifesto principal de dependências.
• uv.lock fixa o ambiente resolvido, então uv sync --frozen é recomendado por padrão.
• requirements.txt é mantido apenas para instalação legada baseada em pip.

② Iniciar a WebUI 🌐

Observe que você precisa executar os seguintes comandos no diretório raiz do projeto MoneyPrinterTurbo.

Windows
.\webui.bat

Você também pode executar webui.bat no CMD. O webui.bat prefere o .venv do projeto ou o Python empacotado do pacote portátil. Se nenhum Python do projeto for encontrado, mas o uv estiver instalado, ele automaticamente recorre a uv run streamlit. Para permitir que outros dispositivos na sua LAN acessem a WebUI, execute set MPT_WEBUI_HOST=0.0.0.0 antes de executar webui.bat.

macOS ou Linux
sh webui.sh

O script usa automaticamente o ambiente virtual do projeto ou o uv e seleciona uma porta local disponível. Para permitir acesso de outros dispositivos na sua LAN, execute:

MPT_WEBUI_HOST=0.0.0.0 sh webui.sh

Após o lançamento, o navegador abrirá automaticamente.

③ Iniciar o Serviço de API 🚀

uv run python main.py

Se você já ativou o ambiente virtual manualmente, ainda pode executar:

python main.py

④ Modo CLI Puro (Sem Navegador) ⌨️

Se você não puder usar um navegador ou redirecionamento de porta, gere vídeos diretamente da linha de comando. O comando de geração completa mais simples é:

uv run python cli.py --video-subject "How AI is changing everyday life"

Para a referência completa de comandos, descrições de parâmetros e instruções de uso, execute:

uv run python cli.py --help

Síntese de Voz 🗣

O provedor padrão é o Edge TTS gratuito, mostrado como Azure TTS V1 na WebUI. O MoneyPrinterTurbo também suporta Azure TTS V2, SiliconFlow TTS, Google Gemini TTS, Xiaomi MiMo TTS, ElevenLabs TTS, Chatterbox TTS auto-hospedado e um modo sem voz.

Selecione um provedor e uma voz na WebUI e siga as instruções na tela para quaisquer credenciais necessárias. O Edge TTS não requer uma chave de API; Azure TTS V2 e outros provedores de nuvem exigem credenciais de suas respectivas plataformas. Veja as vozes disponíveis do Edge TTS na lista de vozes.

Geração de Legendas 📜

Dois modos de geração de legendas estão disponíveis:

  • edge: Usa timestamps do TTS, roda rapidamente sem GPU e é o modo padrão.
  • whisper: Usa a transcrição local faster-whisper quando é necessária uma linha do tempo de legendas mais precisa. O modelo é baixado no primeiro uso.

Defina subtitle_provider em config.toml para alternar os modos. O Whisper usa o modelo large-v3 de aproximadamente 3 GB por padrão. Para usar o modelo menor e mais rápido large-v3-turbo de aproximadamente 1,6 GB:

[app]
subtitle_provider = "whisper"

[whisper]
model_size = "large-v3-turbo"
No primeiro uso, o Whisper baixa automaticamente o modelo do Hugging Face. Se o download automático falhar, baixe o whisper-large-v3 manualmente do Hugging Face.

Após extrair o modelo, coloque o diretório inteiro em .\MoneyPrinterTurbo\models. O caminho final deve ser .\MoneyPrinterTurbo\models\whisper-large-v3:

MoneyPrinterTurbo
  ├─models
  │   └─whisper-large-v3
  │          config.json
  │          model.bin
  │          preprocessor_config.json
  │          tokenizer.json
  │          vocabulary.json

Perguntas Frequentes 🤔

Como publico no TikTok, Instagram ou YouTube Shorts?

Crie uma conta e chave de API no Upload-Post, depois adicione as seguintes configurações em [app] no config.toml:

[app]
upload_post_enabled = true
upload_post_api_key = "sua-chave-api"
upload_post_username = "seu-usuario"
upload_post_platforms = ["tiktok", "instagram", "youtube"]
upload_post_auto_upload = true
upload_post_youtube_privacy_status = "public"

Reinicie o aplicativo após salvar. Os vídeos gerados serão então publicados automaticamente nas plataformas configuradas. A privacidade do YouTube pode ser definida como public, unlisted ou private.

RuntimeError: No ffmpeg exe could be found

Normalmente, o ffmpeg será baixado e detectado automaticamente. No entanto, se o seu ambiente tiver problemas que impeçam downloads automáticos, você pode encontrar o seguinte erro:

RuntimeError: No ffmpeg exe could be found.
Install ffmpeg on your system, or set the IMAGEIO_FFMPEG_EXE environment variable.

Nesse caso, você pode baixar o ffmpeg de https://www.gyan.dev/ffmpeg/builds/, descompactá-lo e definir ffmpeg_path para o seu caminho de instalação real.

[app]
# Defina de acordo com o seu caminho real; note que os separadores de caminho do Windows são \\
ffmpeg_path = "C:\\Users\\harry\\Downloads\\ffmpeg.exe"
OSError: [Errno 24] Too many open files

Este problema é causado pelo limite do sistema no número de arquivos abertos. Você pode resolvê-lo modificando o limite de arquivos abertos do sistema.

Verifique o limite atual:

ulimit -n

Se estiver muito baixo, você pode aumentá-lo, por exemplo:

ulimit -n 10240
Falha no download do modelo Whisper

Erros como:

LocalEntryNotFoundError: Cannot find an appropriate cached snapshot folder...
An error occurred while synchronizing the model Systran/faster-whisper-large-v3...

Solução: Veja como baixar o modelo manualmente do Hugging Face na seção Geração de Legendas.
